Baixar para Android .APKAndroid 7 ou superior · 3,2 MB · versão 1.1.0
Como instalar no celular
  1. Baixe o APK e abra o arquivo.
  2. Se solicitado, permita que seu navegador instale este aplicativo.
  3. Abra o Nosso Lar e conecte a conta da família para sincronizar.
NO COMPUTADOR

Nosso Lar para Windows

O mesmo aplicativo da casa, com mais espaço para planejar juntos.

Baixar para Windows .EXEWindows 10 ou 11 · 64 bits · 117 MB · versão 1.1.0
Como instalar no computador
  1. Baixe e abra o instalador.
  2. Se já usa a versão anterior, faça um backup no app antes de atualizar.
  3. Instale por cima da versão anterior e conecte a mesma conta da família.

Por ser uma distribuição independente, o Windows pode solicitar uma confirmação antes de abrir o instalador.
